# 🛒 SmartCart: E-Commerce Customer Segmentation System

## 📌 Overview

SmartCart is an end-to-end Machine Learning project that analyzes customer purchasing behavior and segments customers into meaningful groups using unsupervised learning techniques. The project helps businesses understand customer characteristics, improve targeted marketing, and support data-driven decision-making.

## 🚀 Features

* Data Cleaning and Preprocessing
* Exploratory Data Analysis (EDA)
* Customer Behavior and Dataset Characteristic Analysis
* Feature Engineering
* Categorical Encoding
* Feature Scaling
* Outlier Detection and Removal
* Dimensionality Reduction using PCA
* Customer Segmentation using:

  * K-Means Clustering
  * Agglomerative Hierarchical Clustering
* Cluster Evaluation using:

  * Elbow Method
  * Silhouette Score
* 2D and 3D Data Visualization
* Cluster-wise Customer Insights
